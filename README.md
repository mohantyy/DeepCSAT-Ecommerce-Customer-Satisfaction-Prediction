# DeepCSAT-Ecommerce-Customer-Satisfaction-Prediction
DeepCSAT: Deep Learning (ANN) and NLP system to predict E-Commerce Customer Satisfaction (CSAT) scores in real time from customer support interactions, feedback, and operational telemetry. Built with TensorFlow/Keras, NumPy, SciPy, and Streamlit (AlmaBetter AI Engineering Capstone).
